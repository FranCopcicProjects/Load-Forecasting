# Load-Forecasting
Short-term transmission network load forecasting is an important part of planning and managing power systems, as it enables more reliable network operation, more efficient utilization of generation capacities, and reduced operating costs. In this thesis, a transmission network load forecasting system for the Croatian transmission network was developed using various machine learning models. The implemented models include Linear Regression, Random Forest, XGBoost, AutoML, and the Long Short-Term Memory (LSTM) neural network.

Historical transmission network load data and meteorological data covering the period from 2023 to 2025 were used to train the models. The impact of one-hour and twenty-four-hour time lags on forecasting performance was analyzed, while the obtained results were evaluated using the MSE, RMSE, MAE, and MAPE metrics. In addition to implementing the forecasting models, a system was developed that enables the user to select the forecast visualisation type and the starting date through a terminal. The system then displays forecast graphs, monthly error distribution graphs, and the values of the evaluation metrics for each implemented model.

The obtained results showed that incorporating time-lag features significantly improves the forecasting accuracy of all implemented models. The XGBoost model achieved the best overall performance, obtaining the lowest values for all evaluation metrics. The results demonstrate that tree-based machine learning models provide an effective solution for the short-term forecasting of transmission network load.
